## 📖 Sobre o Projeto

KLAUSCORP.AI é um sistema avançado de Inteligência Artificial para prevenção de fraude em tempo real, com:

- ✅ Autenticação 2FA segura (Email + Google Authenticator)
- ✅ Criptografia Post-Quantum (ML-KEM-768, ML-DSA-65)
- ✅ Zero Trust Architecture
- ✅ Rate Limiting em 3 camadas
- ✅ Suporte Técnico 24/7
- ✅ 7 Serviços Especializados

## 🚀 Quick Start

```bash
# Instalação
npm install

# Desenvolvimento
npm run dev

# Produção
npm start
```

Servidor rodará em: `http://localhost:3000`
